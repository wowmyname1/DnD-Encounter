# Спецификация D&D Encounter Builder

## Статус

Документ находится в процессе наполнения.

## 1. Обзор

D&D Encounter Builder - одностраничное приложение для проведения боёв D&D 5e. Приложение работает в браузере без сервера и без сборки.

Основной фокус:

- управление персонажами;
- бой и инициатива;
- HP, урон, лечение, временные HP;
- кубики и режимы распределения бросков;
- статусы и триггеры;
- заклинания;
- карта с токенами;
- пользовательские расширения.

## 2. Цели приложения

- Быстро создавать PC и NPC.
- Вести бой с порядком инициативы и раундами.
- Применять урон, лечение и временные HP.
- Бросать кубики с режимами одиночного применения, AoE и разброса.
- Управлять статусами с длительностью и триггерами.
- Использовать карту с токенами и визуальным порядком боя.
- Расширять систему пользовательскими статусами и заклинаниями.
- Держать код модульным без сборщиков и фреймворков.

## 3. Пользовательские роли

### ДМ

- Создаёт NPC.
- Размещает токены на карте.
- Запускает бой и переключает ходы.
- Применяет урон, лечение и статусы.
- Следит за длительностями эффектов.
- Использует каталоги статусов и заклинаний.

### Игрок

- Создаёт или получает PC.
- Бросает кубики.
- Применяет результаты к персонажам.
- Использует заклинания и статусы.
- Следит за HP и эффектами.

## 4. Технологические ограничения

- Без серверной части.
- Без сборщика.
- Только HTML, CSS и vanilla JavaScript.
- Интерфейс должен работать в современном браузере.
- Данные во время сессии хранятся в памяти страницы.
- Сохранение состояния между перезагрузками планируется через localStorage.
- Не используются внешние библиотеки.

## 5. Структура проекта

### Базовые файлы

- index.html - разметка приложения.
- styles.css - стили приложения.
- utils.js - базовые утилиты: escapeHtml, AppEvents, window.__inTrigger.

### Основные модули

- app-state.js - глобальное состояние приложения.
- app-dice.js - парсер кубиков, броски, режимы, выбор кубиков.
- app-hp.js - урон, лечение, временные HP, HP-попапы.
- app-combat.js - бой, инициатива, ходы, события turn:start и turn:end.
- app-ui.js - рендеринг панелей персонажей, токенов, инициативы, превью.
- app-char.js - персонажи, создание, редактирование, детали, пресеты.
- app-core.js - вспомогательные взаимодействия и служебные функции.
- app-setup.js - инициализация, примеры бросков, глобальные слушатели.

### Расширения

- extensions-data.js - каталоги статусов и заклинаний.
- extensions-wizards.js - конструкторы статусов и заклинаний.
- extensions-editor.js - редактор узлов логики.
- extensions-triggers.js - исполнение триггерных деревьев статусов.
- extensions-spells.js - применение заклинаний и выбор целей.
- extensions-init.js - инициализация расширений и подписки на события.

### Тесты и документы

- tests/smoke.sh - базовый smoke-тест структуры проекта.
- SPECIFICATION.md - текущая спецификация.

## 6. Основные сущности

### Character

Описание персонажа или NPC.

Поля:

- id - уникальный идентификатор.
- type - тип персонажа: pc или npc.
- name - имя.
- cls - класс или тип существа.
- level - уровень.
- ac - класс брони.
- init - бонус инициативы.
- hpMax - максимальные HP.
- hpCur - текущие HP.
- color - цвет персонажа и токена.
- description - описание.
- abilities - характеристики D&D 5e.
- spellAbility - заклинательная характеристика.
- spellSaveDC - сложность спасброска.
- cantripBonus - бонус атаки заговора.
- useHpFormula - использовать ли формулу HP.
- hpBase - базовое HP.
- hpPerLevel - HP за уровень.
- hpConFactor - коэффициент модификатора Телосложения.
- statuses - активные статусы.
- x - координата токена по горизонтали.
- y - координата токена по вертикали.

### Abilities

Характеристики персонажа:

- str - Сила.
- dex - Ловкость.
- con - Телосложение.
- int - Интеллект.
- wis - Мудрость.
- cha - Харизма.

Формула модификатора характеристики:

modifier = floor((score - 10) / 2)

### ActiveRoll

Активный бросок кубиков.

Поля:

- expression - исходное выражение броска.
- dice - список выпавших кубиков.
- modifier - модификатор броска.
- mode - режим применения: single, aoe, spread.
- applyType - тип применения: damage, heal, temp.
- aoeTargets - выбранные цели для AoE.
- maxSelected - максимум одновременно активных кубиков.

### Combat

Состояние боя.

Поля:

- combatActive - активен ли бой.
- turnOrder - порядок инициативы.
- currentTurnIndex - индекс текущего персонажа.
- round - номер раунда.

### Status

Активный статус на персонаже.

Примерные поля:

- id - уникальный идентификатор экземпляра статуса.
- name - название статуса.
- icon - иконка статуса.
- duration - длительность.
- remaining - оставшееся время.
- source - источник статуса.
- logic - логика срабатывания и эффектов.

## 8. Механика персонажей

### Создание персонажа

- Пользователь открывает модальное окно для PC или NPC.
- Заполняются имя, класс, уровень, AC, инициатива и HP.
- Задаются характеристики: Сила, Ловкость, Телосложение, Интеллект, Мудрость, Харизма.
- Можно включить формулу HP.
- Можно выбрать цвет персонажа.
- Можно задать описание.
- Можно указать заклинательную характеристику, сложность спасброска и бонус заговора.

### Формула HP

- Если включена формула HP, максимальные HP считаются автоматически.
- Модификатор Телосложения считается как floor((CON - 10) / 2).
- Для первого уровня используется базовое HP плюс модификатор Телосложения, умноженный на коэффициент.
- Для каждого следующего уровня используется HP за уровень плюс модификатор Телосложения, умноженный на коэффициент.
- Итоговое значение округляется.
- Минимальное значение максимальных HP - 1.

### Редактирование персонажа

- Кнопка редактирования открывает то же модальное окно с уже заполненными полями.
- При сохранении данные персонажа обновляются.
- Если изменился максимум HP, текущие HP не должны превышать новый максимум.
- Редактирование не должно автоматически удалять статусы персонажа.

### Развёрнутая карточка

- Кнопка деталей открывает отдельное модальное окно.
- В деталях показываются характеристики с модификаторами.
- Показываются текущие и максимальные HP.
- Показываются AC и инициатива.
- Показываются настройки формулы HP.
- Показывается описание персонажа.

### Каталог пресетов

- Пользователь может открыть каталог заранее созданных персонажей.
- Пресет создаёт нового персонажа с заранее заданными параметрами.
- Пресеты могут быть как PC, так и NPC.
- Пресет должен корректно создавать персонажа без ручного заполнения формы.

## 9. Механика боя

### Начало боя

- Бой начинается отдельной кнопкой.
- Для всех персонажей рассчитывается инициатива.
- Персонажи сортируются по инициативе.
- Определяется первый активный персонаж.
- Номер раунда устанавливается в 1.

### Порядок ходов

- Текущий персонаж отображается в интерфейсе.
- Кнопка следующего хода передаёт ход.
- Перед передачей хода обрабатываются эффекты конца хода текущего персонажа.
- После передачи хода обрабатываются эффекты начала хода нового персонажа.

### Раунды

- Когда список инициативы пройден, номер раунда увеличивается.
- Мёртвые персонажи могут исключаться из порядка боя.
- Если живых участников не осталось, бой может быть автоматически сброшен.

### События боя

- turn:end - событие конца хода текущего персонажа.
- turn:start - событие начала хода нового персонажа.
- Эти события используются статусами, триггерами и расширениями.

### Сброс боя

- Сброс боя останавливает боевой режим.
- Очищается порядок инициативы.
- Сбрасывается текущий индекс хода.
- Сбрасывается номер раунда.
- Интерфейс возвращается в небоевой режим.

## 10. Карта и токены

### Токены

- Каждый персонаж имеет токен на карте.
- Цвет токена соответствует цвету персонажа.
- Токен можно перетаскивать мышью.

### Координаты

- Позиция токена хранится в полях x и y персонажа.
- Координаты ограничиваются границами карты.

### Взаимодействие

- Клик по токену может применять активный бросок в зависимости от режима.
- В режиме single активная сумма применяется к персонажу.
- В режиме spread применяется один выбранный кубик.
- В режиме aoe клик может добавлять или убирать персонажа из списка целей.

### Отображение боя

- Активный персонаж может подсвечиваться.
- Порядок инициативы отображается отдельным списком.
- HP и статусы персонажа отражаются в карточке.
